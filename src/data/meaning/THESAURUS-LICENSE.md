# Moby Thesaurus II

`thesaurus.txt.gz` contains the unmodified `words.txt` corpus distributed in
`moby@1.1.2`, compressed with gzip. No executable package code is bundled.

Source: https://github.com/words/moby
Compiler: Grady Ward. The Moby lexicon was placed in the public domain.
It may be used, sold, reworked, excerpted, and redistributed.

This corpus includes synonyms and related terms, not exclusively synonyms.
Wordsmith filters candidates and validates branch relationships separately.
